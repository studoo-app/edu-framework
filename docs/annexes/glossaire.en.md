# Glossary

This Glossary contains definitions of the technical terms used in the framework documentation.

## A

### Alpha Release
An alpha release is a version of a piece of software that is still under development and is not yet ready for production use.

### API
An API (Application Programming Interface) is a set of definitions and protocols that allow pieces of software to communicate with each other.

- [https://fr.wikipedia.org/wiki/Interface_de_programmation](https://fr.wikipedia.org/wiki/Interface_de_programmation){:target="_blank"}

### Architecture
Software architecture is the structure of a software system. It defines the components, the relationships and the principles that guide the design and evolution of the system.

- [https://fr.wikipedia.org/wiki/Architecture_logicielle](https://fr.wikipedia.org/wiki/Architecture_logicielle){:target="_blank"}

### Autoloading
Autoloading is a mechanism that automatically loads PHP classes without having to include them manually.

## B

### Beta Release
A beta release is a version of a piece of software that is still under development and is ready to be tested by users.

### Bug
A bug is a defect or an error in a piece of software that causes a malfunction or unexpected behavior.

## C

### CLI
CLI (Command Line Interface) is a command-line interface that lets you interact with a computer using text commands.

- [https://fr.wikipedia.org/wiki/Interface_en_ligne_de_commande](https://fr.wikipedia.org/wiki/Interface_en_ligne_de_commande){:target="_blank"}

### Composer
Composer is a dependency manager for PHP. It lets you declare the libraries your project depends on and manage them (install, update, etc.).

- [https://getcomposer.org/](https://getcomposer.org/){:target="_blank"}
- [https://fr.wikipedia.org/wiki/Composer_(logiciel)](https://fr.wikipedia.org/wiki/Composer_(logiciel)){:target="_blank"}
- [https://packagist.org/](https://packagist.org/){:target="_blank"}

### Container
A container is an isolated software environment that runs applications and their dependencies.

- [https://www.docker.com/resources/what-container](https://www.docker.com/resources/what-container){:target="_blank"}
- [https://fr.wikipedia.org/wiki/Conteneur_(informatique)](https://fr.wikipedia.org/wiki/Conteneur_(informatique)){:target="_blank"}

### CRUD
CRUD (Create, Read, Update, Delete) is an acronym for the basic operations used to manage data in a database.

- [https://fr.wikipedia.org/wiki/CRUD](https://fr.wikipedia.org/wiki/CRUD){:target="_blank"}


## D

### Database server
A database server is a piece of software that stores, processes and manages the data of a database.

- [https://www.mysql.com/](https://www.mysql.com/){:target="_blank"}

### DEPRECATE
A piece of code is deprecated when it is **obsolete** and it is recommended to stop using it.

### Docker
Docker is a lightweight virtualization platform that makes it easy to isolate and manage applications in containers.

- [https://www.docker.com](https://www.docker.com){:target="_blank"}

### Dotenv
Dotenv is a library that loads environment variables from a `.env` file.

## E

### Execution server
An execution server is a piece of software that runs web applications.
For PHP programming, Apache, Nginx or a built-in server such as PHP's are often used.

In development, PHP's built-in server is often used to test applications locally.
```
php -S localhost:8000
```
Edu Framework uses the command:
```
php bin/edu start
```

## F

### Feature
A feature is a functionality or characteristic of a piece of software.

### Final Release
A final release is a version of a piece of software that is ready for production use.

### Framework
A framework is a set of structured software components that make application development easier.

- [https://fr.wikipedia.org/wiki/Framework](https://fr.wikipedia.org/wiki/Framework){:target="_blank"}

## G

### GET
A GET request is an HTTP request method used to request data from a web server.
You can use a GET request to send data to a server through the URL.

```
example: http://example.com/api/users?name=John&age=30
```

### GIT
Git is a distributed version control system. It is an essential tool for developers.

- [https://git-scm.com/](https://git-scm.com/){:target="_blank"}
- [https://fr.wikipedia.org/wiki/Git](https://fr.wikipedia.org/wiki/Git){:target="_blank"}

## H

### HTTP
HTTP (Hypertext Transfer Protocol) is a communication protocol used to transfer data on the web.

- [https://developer.mozilla.org/fr/docs/Web/HTTP](https://developer.mozilla.org/fr/docs/Web/HTTP){:target="_blank"}

## J

### Javascript
JavaScript is a scripting language mainly used for interactive web pages.

- [https://developer.mozilla.org/fr/docs/Web/JavaScript](https://developer.mozilla.org/fr/docs/Web/JavaScript){:target="_blank"}
- [https://fr.wikipedia.org/wiki/JavaScript](https://fr.wikipedia.org/wiki/JavaScript){:target="_blank"}
- [https://www.w3schools.com/js/](https://www.w3schools.com/js/){:target="_blank"}

### JSON
JSON (JavaScript Object Notation) is a text data format that represents objects in a simple, readable way.

- [https://www.json.org/](https://www.json.org/){:target="_blank"}
- [https://fr.wikipedia.org/wiki/JavaScript_Object_Notation](https://fr.wikipedia.org/wiki/JavaScript_Object_Notation){:target="_blank"}
- [https://www.json.org/json-fr.html](https://www.json.org/json-fr.html){:target="_blank"}

## L

### LTS (Long Term Support)
LTS (Long Term Support) is a version of a piece of software that benefits from long-term support.

- [https://fr.wikipedia.org/wiki/Versionnage](https://fr.wikipedia.org/wiki/Versionnage){:target="_blank"}
- [https://semver.org/](https://semver.org/){:target="_blank"}

## M

### Markdown
Markdown is a lightweight markup language created in 2004 by John Gruber with the help of Aaron Swartz.
Its goal is to offer a syntax that is easy to read and write.
A Markdown document can be read as is, without looking as though it has been marked up or formatted with special instructions.
Uses: writing documentation, README files, forums, blogs, etc.

- [https://fr.wikipedia.org/wiki/Markdown](https://fr.wikipedia.org/wiki/Markdown){:target="_blank"}
- [https://www.markdownguide.org/cheat-sheet/](https://www.markdownguide.org/cheat-sheet/){:target="_blank"}

### MVC
Model-view-controller (MVC) is a software architecture pattern for graphical interfaces, introduced in 1978 and very popular for web applications.

- [MVC architecture](../build/concept-mvc.md){:target="_blank"}

## P

### PDO
PDO (PHP Data Objects) is a PHP extension that defines an interface for accessing databases.

- [https://www.php.net/manual/fr/book.pdo.php](https://www.php.net/manual/fr/book.pdo.php){:target="_blank"}
- [https://fr.wikipedia.org/wiki/PHP_Data_Objects](https://fr.wikipedia.org/wiki/PHP_Data_Objects){:target="_blank"}

### PHP
PHP (a recursive acronym for PHP: Hypertext Preprocessor) is a general-purpose, open source scripting language, specially designed for web application development.

- [https://www.php.net/](https://www.php.net/){:target="_blank"}
- [https://fr.wikipedia.org/wiki/PHP](https://fr.wikipedia.org/wiki/PHP){:target="_blank"}

### POST
A POST request is an HTTP request method used to send data to a web server.

## R

### Refactoring
Refactoring is the process of modifying a piece of software's source code to improve its readability, maintainability and performance, without changing its behavior.

- [https://fr.wikipedia.org/wiki/Refactoring](https://fr.wikipedia.org/wiki/Refactoring){:target="_blank"}

### Release
A release is a version of a piece of software that is ready to be distributed.

- [https://fr.wikipedia.org/wiki/Versionnage](https://fr.wikipedia.org/wiki/Versionnage){:target="_blank"}
- [https://semver.org/](https://semver.org/){:target="_blank"}

### Release Candidate
A release candidate is a version of a piece of software that is ready for production use, but requires further testing.

### Repository
A repository is a storage space that contains the files and metadata of a software project.

### Route
A route is a URL associated with a specific action in a web application.

## S

### Semantic versioning
Semantic versioning is a set of rules and conventions for assigning version numbers to software.
Major.Minor.Patch (e.g. 1.2.3)

- [https://semver.org/](https://semver.org/){:target="_blank"}

### Singleton
The singleton is a design pattern that ensures a class has only one instance and provides a global access point to that instance.

- [https://fr.wikipedia.org/wiki/Singleton_(patron_de_conception)](https://fr.wikipedia.org/wiki/Singleton_(patron_de_conception)){:target="_blank"}

### SQL
SQL (Structured Query Language) is a standardized computer language used to work with relational databases.

- [https://fr.wikipedia.org/wiki/Structured_Query_Language](https://fr.wikipedia.org/wiki/Structured_Query_Language){:target="_blank"}
- [https://sql.sh/](https://sql.sh/){:target="_blank"}

### Syntax
Syntax is the set of rules that define the structure and form of the elements of a programming language.
Each programming language has its own syntax.

- [https://developer.mozilla.org/fr/docs/Glossary/Syntax](https://developer.mozilla.org/fr/docs/Glossary/Syntax){:target="_blank"}

## T

### Template engine
A template engine is a tool that separates presentation code from logic code (the View layer of the MVC pattern).

- [https://fr.wikipedia.org/wiki/Moteur_de_template](https://fr.wikipedia.org/wiki/Moteur_de_template){:target="_blank"}

## V

### Versioning
Versioning is a system for managing the different versions of a software project.

- [https://fr.wikipedia.org/wiki/Gestion_de_versions](https://fr.wikipedia.org/wiki/Gestion_de_versions){:target="_blank"}

## W

### Web server
A web server is a piece of software that stores, processes and delivers data on the web.

- [https://fr.wikipedia.org/wiki/Serveur_web](https://fr.wikipedia.org/wiki/Serveur_web){:target="_blank"}
- [https://www.nginx.com/](https://www.nginx.com/){:target="_blank"}

## Y

### YAML
YAML (YAML Ain't Markup Language) is a human-readable data serialization format.

- [https://yaml.org/](https://yaml.org/){:target="_blank"}
- [https://fr.wikipedia.org/wiki/YAML](https://fr.wikipedia.org/wiki/YAML){:target="_blank"}
