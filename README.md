The "Edu Framework" project addresses a recurring question raised during our training courses: "How do you make the transition to a framework like Symfony?".

The main goal of "Edu Framework" is to provide a set of tools, guides and learning resources that help developers, whether beginners or experienced, make their transition to the Symfony framework easier. The project aims to cover both the fundamentals and the advanced techniques of Symfony, with a focus on development best practices.

> This framework is not suitable for production use. It is intended for educational purposes.
